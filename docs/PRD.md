# 1. 项目概述

## 1.1 项目名称

记账助手（暂定）

---

## 1.2 产品定位

记账助手是一款基于大语言模型（LLM）的移动端智能财务管理应用。

用户无需填写复杂表单，只需要通过自然语言描述消费行为，AI 即可完成：

- 消费记录
- 自动分类
- 账单查询
- 消费分析
- 预算规划

帮助用户降低记账成本，并形成个人消费管理习惯。

---

## 1.3 产品背景

传统记账工具存在以下问题：

### 1. 记账流程复杂

传统流程：

```
打开App
↓
选择分类
↓
输入金额
↓
填写备注
↓
保存
```

导致用户难以长期坚持。

---

### 2. 数据记录与分析割裂

传统记账软件只能告诉用户：

> 本月消费 3000 元

但无法回答：

- 为什么花这么多？
- 哪些消费可以减少？
- 当前消费是否合理？

---

### 3. 用户缺少预算规划能力

多数用户：

- 不知道如何分配收入
- 不知道每天合理消费额度
- 不知道如何完成存钱目标

---

# 2. 用户分析

具有以下需求的人群：

- 希望记录日常消费的人
- 希望控制消费支出的人

- 希望了解消费习惯的人


---

## 2.2 用户痛点

|痛点|描述|
|-|-|
|记录麻烦|传统记账步骤过多|

# 4. 产品功能设计

---

# 4.1 AI聊天记账（P0）

## 功能描述

用户通过自然语言输入消费信息。

AI自动识别：

- 消费名称
- 金额
- 时间
- 分类


---

## 用户输入示例

```
今天早餐4元，公交4.5元，网易云会员5元
```

---

## AI解析结果

```json
{
  "records":[
    {
      "name":"早餐",
      "amount":4,
      "category":"餐饮"
    },
    {
      "name":"公交",
      "amount":4.5,
      "category":"交通"
    },
    {
      "name":"网易云会员",
      "amount":5,
      "category":"娱乐"
    }
  ]
}
```

---

## 功能要求

支持：

### 多笔消费

例如：

```
午饭20，奶茶8，打车15
```

解析为：

3条消费记录。

---

### 时间识别

例如：

```
昨天晚上吃火锅68
```

自动识别：

```
日期：昨天
金额：68
分类：餐饮
```

---

### 信息不足处理

用户：

```
买衣服了
```

AI：

```
请告诉我购买金额，我才能帮你记录。
```

---

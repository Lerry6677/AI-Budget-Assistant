# AI Budget Assistant

一个基于大语言模型的聊天式智能记账助手。

## 项目介绍

传统记账工具需要用户主动填写账单，
导致记录成本高、坚持困难。

本项目希望通过自然语言交互，
让用户像聊天一样完成记账、预算管理和消费分析。

例如：

用户：
> 今天早餐花了8块，公交4块

AI：
> 已记录：
> 早餐 - 8元
> 交通 - 4元
>
> 今日消费12元，本月剩余预算xxx元。
